# Básico 04 - ES Modules (ESM) 🪂

API REST estructurada en capas que implementa el estándar moderno de JavaScript (ES Modules) mediante `import` / `export` y la configuración `"type": "module"`, con una temática de Battle Royale.

## 🚀 Cómo ejecutar

1. Instala las dependencias:
   ```bash
   npm install
    ```

2. Iniciar en modo desarrollo
    ```bash
    npm run dev
    ```
